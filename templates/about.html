How it works

Nine agents, one traceable verdict.

Misinformation Shield doesn't ask a language model "is this true?" and print whatever it says. Every investigation runs through nine independent, single-purpose agents — each one persists its own status and output, so the whole process is auditable after the fact.

01

Claim extraction

Pulls the specific, checkable factual claim out of free text, a headline, or a link — filtering out opinion and filler.

02

Claim analysis

Normalizes and classifies the claim so the right research strategy gets used.

03

Web research

Searches live sources for evidence — supporting, contradicting, or neutral.

04

Knowledge base (RAG)

Searches a private, curated knowledge base in parallel with the web research.

05

Evidence classification

Sorts every piece of evidence found into supporting, contradicting, neutral, or contextual.

06

Source credibility

Scores each source's track record. This is a weight on confidence, never a verdict override.

07

Contradiction check

Deliberately searches for evidence the claim is false — "<claim> debunked", "<claim> fact check" — so confirmation bias can't under-surface disconfirming evidence.

08

Verification

Computes the final verdict and confidence score. No evidence means unverifiable — never a guess. Thin evidence caps confidence automatically.

09

Report generation

Assembles the citable report you see, with every source attached and exportable as a PDF.

Verdict scale

Verified · Mostly True · Partially True · Misleading · Mostly False · False · Unverifiable
